### 👩‍💻 About me

- 🌱 CS student who enjoys building **backends that are clean, layered and easy to reason about**
- 🏗️ Built **UNI-CHAIN**, a blockchain-based supply-chain tracker for agricultural produce, for **Smart India Hackathon**
- ☕ Spend most of my time in **Java + Spring Boot** — REST APIs, DTOs, custom exceptions, design patterns
- 🤖 Exploring **NLP & OCR** — built a tool that reads legal contracts and flags risky clauses
- 🧩 Practicing **DSA in C++** on the side
- 💬 Ask me about **Spring Boot, REST API design, React, or hackathons**
- 🚀 Currently: learning in public and shipping one small thing every week
